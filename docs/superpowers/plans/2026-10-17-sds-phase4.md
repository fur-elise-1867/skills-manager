# SDS Phase 4 — Product Completion Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Hoàn thiện Local Install, Library, settings/activity, onboarding/dashboard và thông báo bản app nội bộ để đủ phạm vi chức năng 1.0.

**Architecture:** Local/Store là hai origin rõ ràng dùng chung prepared artifact, coordinator, deployment và recovery. UI quản lý đọc dữ liệu thật từ SDS repository. App-release chỉ kiểm tra metadata và đưa link bộ cài nội bộ; không dùng public updater hoặc tự cài app.

**Tech Stack:** React/TypeScript, Tauri/Rust, SQLite migrations, Vitest/Testing Library, Rust fixtures/fake HTTP và Windows installer.

**Spec:** [Delivery design §3–11](../specs/2026-10-16-sds-app-delivery-design.md), [SRS CAT-05/LIB-01/SET-01/LOG-01](../../sds-phase1/SRS.md), [review/G2](2026-10-17-sds-phase3-5-review.md), [Phase 3](2026-10-17-sds-phase3.md).

Trạng thái draft; paths tương đối root app đã tích hợp G2 + Phase 3. `R` = `src-tauri/src/sds`; `F` = `src/features/sds`. Không coi các interface mới bên dưới đã tồn tại.

## Global Constraints

- Local Install: một ZIP/7z chứa đúng một skill root; không import folder, không giải nén đệ quy archive lồng nhau; không chạy script.
- Local package không giả Store ID/release/compatibility; MCP chưa khai báo là unknown; không tự nhận update Store.
- Mọi entry point cài đặt phải đi qua coordinator; snapshot/restore và target isolation từ Phase 2–3 được giữ.
- Store: chỉ thêm file/folder/package mới; không sửa, di chuyển hoặc xóa file hiện có, kể cả cấu hình, dependency manifest, security hoặc migration cũ.
- Database Store: chỉ thêm bảng/job/đối tượng mới khi cần. Không sửa hoặc xóa bảng, cột, index hay đối tượng hiện hữu. Không chạy script reset/recreate DB dùng chung.
- HTTP chỉ cho loopback trong cấu hình development. Môi trường nội bộ dùng HTTPS có xác minh chứng chỉ; không cho tắt TLS verification.
- Windows, English mặc định, no public network dependency; không SSO, telemetry, TTL 14 ngày, offline 72 giờ, retention 30 ngày hoặc auto-update từ copy Stitch.
- 1440×860 / minimum 1100×640; token/theme giữ amendments Phase 0–1; không thêm CDN/font requests.

## Review Focus

1. File local bị thay giữa chọn và prepare: đóng băng bản copy backend, hash/verify đúng bytes triển khai (P4.1).
2. Local ID collision hoặc tên giống skill Store: không nhận quyền Store, không ghi đè ngoài review (P4.1).
3. Library filtered selection mất/đổi sau refresh: chỉ hành động đúng ID đã review; không cài nhầm release (P4.2).
4. Export logs rò Authorization/token/MCP/path nhạy cảm từ error thô: allowlist fields và redact trước ghi/export (P4.3).
5. App feed trả version/link bất thường, redirect public hoặc dùng nhầm skill version: giữ bản đang dùng, báo unavailable, không auto-download (P4.4).

**Depends:** G2, P3.1–3; UI import mới cần review cụ thể do W02 chỉ có tab. **SRS:** CAT-05, INS-01..07, MCP-01..05, OFF-01. **Screens:** W02,W04,W05,W06.

**Files:** Create `R/local_import.rs`, `R/artifacts.rs`, `R/tests/local_import.rs`, `F/local/LocalInstallPage.tsx`, `F/local/LocalInstallPage.test.tsx`; modify `R/contracts.rs`, `R/packages/mod.rs`, `R/repository.rs`, `R/operations.rs`, `R/journal.rs`, `R/library.rs`, `R/removal.rs`, `R/presets.rs`, `R/commands.rs`, `R/mod.rs`, `R/tests/mod.rs`, `src-tauri/src/lib.rs`, `F/contracts.ts`, `F/api.ts`, `F/SdsShell.tsx`, `F/catalog/CatalogPage.tsx`, `F/install/BatchFlow.tsx`; new numbered migration for origin metadata, v2 contract fixtures and contract runner.

**Interfaces đề xuất:**

- `ArtifactOrigin = Store { profileId, skillId, releaseId } | Local { importId, sha256 }`; importId `local:<sha256-archive>`, stable cho cùng bytes; local content version là digest, không Store sequence/version.
- `InstallableArtifact { artifactId, origin, installName, contentFingerprint, manifest, compatibleAgents: Option<Vec<AgentKey>>, requiredMcps: Option<Vec<String>> }`; local chưa có metadata khai báo dùng None, không suy diễn từ description. Store adapter giữ nguyên immutable Release DTO/provider v1.
- `prepare_local_import(path: PathBuf) -> Result<LocalImportPreview,SdsError>` với preview `{artifactId, fileName, format, sizeBytes, sha256, installName, mcp}`; file được backend copy giới hạn size sang private staging trong khi hash, sau đó dùng package validators hiện có. `prepare_local_install(artifact_id, targets: Vec<TargetSelection>) -> Result<PreparedBatch,SdsError>` dùng batch P3.3.
- Mở rộng `OperationContext` của Phase2, giữ `Store(SessionContext)`, `Cached(CacheInstallContext)`, `LocalMaintenance { runtimeEpoch }`; thêm `LocalImport { runtimeEpoch }` cho local archive không cần tài khoản/network. Local import vẫn phải review/root/fingerprint/runtime guard; không thay hoặc bypass Store authorization/offline-account policy bằng local branch.
- Preset member thành discriminated union Store pinned identity | Local artifactId; migration các member cũ thành Store. Local imports khác bytes là artifact khác; không auto-suy ra cùng skill theo display name.
- Để không để local đi qua request Store-only của P3.3, đổi batch input thành `BatchItemRequest { source: Store { skillId, releaseId } | Local { artifactId }, target: TargetSelection }`; `BatchInstallRequest.items` dùng type này. `BatchItem`/LibraryItem/frozen operation trả `artifactId, origin` và Store IDs chỉ trong Store variant. `prepare_local_install` là adapter tạo các Local items rồi gọi cùng BatchService; batch trộn Store/local kiểm tra context từng item, không áp dụng token Store cho local. Migration đọc old frozen Release+SessionContext thành Store variant; unknown shape dừng an toàn, không tự execute journal cũ sau upgrade.

Đề xuất installName: wrapper root nếu archive chỉ có một wrapper hợp lệ; archive root trực tiếp dùng stem filename đã qua validator Windows hiện có. Nếu tên không hợp lệ, yêu cầu người dùng đặt tên hợp lệ trong review rồi validate backend; không âm thầm normalize thành tên có thể đè skill khác. Tên hiển thị không là identity. Import cùng bytes dùng lại cache đã verify, không tạo release trùng.
