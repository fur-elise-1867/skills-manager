Reference Guide

When network synchronizations fail, filters return zero results, or agent capabilities are revoked, Skills Store renders standardized system states:

search_off No Matching Skills

Triggered when combination of keyword query and agent filters matches 0 registry items. Clear filters or adjust search criteria to recover.

sync Catalog Synchronizing

Displayed during delta updates against the internal enterprise SDS skill registry. Skeleton shimmer cards render on the 3x2 stage.

cloud_off Store Offline

Shown when VPN or enterprise authentication drops. Cached skills remain in Library, while store downloads require re-establishing SSO session.
